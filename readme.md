# LifeBalance

LifeBalance is a personal life-balance tracking application designed to help users keep track of different areas of their lives and identify areas that may need more attention.

## Purpose

LifeBalance allows users to record activities across different life categories, including:

- School
- Work
- Family & Friends
- Self-Care
- Health & Fitness
- Fun & Recreation

The application analyzes when activities were last recorded and recommends an area that may need additional attention.

## Current Features

- Life balance dashboard
- Life area tracking
- Activity logging
- Activity history
- Activity deletion
- Focus recommendation
- Responsive interface
